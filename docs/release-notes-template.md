# 发行说明模板

按版本类型选用下方对应模板。正文用简体中文，条目用短句，避免营销式措辞。

---

## 正式发布版（大版本）

适用于有功能新增、行为调整或破坏性变更的版本（如 v2.0.0、v1.8.0）。

```markdown
# vX.Y.Z

用一两句话说明本次发布的主线。

## 新增

- 面向用户的新功能，一条一句。
- 涉及新设置项时，写清入口位置。

## 改进

- 已有功能的体验优化，写清改前改后。

## 修复

- 修掉的问题，写清现象与触发条件。

## 破坏性变更

- 不兼容的改动，写清影响范围与迁移方式。
- 没有此项时整节删除。

## 安装

- 安装包：WSLCC-Setup.exe
- 便携版：WSLCC-win-x64.zip

## 完整改动

- https://github.com/iwvw/wslcc/compare/v<上一版本>...vX.Y.Z
```

---

## 小版本发布（补丁）

适用于修 bug、小优化，不新增功能或破坏兼容（如 v1.7.2）。

```markdown
# vX.Y.Z

用一句话说明本次发布的内容。

## 变更

- 一条一句，按重要性排列。

## 安装

- 安装包：WSLCC-Setup.exe
- 便携版：WSLCC-win-x64.zip
```

---

## 使用约定

- 标题只写版本号，如 `v1.7.2`，不加前缀或后缀。
- 版本号与 git tag 一致，产物命名沿用 `WSLCC-Setup.exe`、`WSLCC-win-x64.zip`。
- 小版本内容少时，可省略「安装」之外的空节，只保留实际有内容的节。
- 对比链接仅正式发布版保留；小版本可省略。
