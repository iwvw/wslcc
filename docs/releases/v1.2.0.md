# v1.2.0

同步官方 wslc 2.9.8-2.9.12 能力。

## 修复

- 版本检测与升级通道：原先跟踪了错误的发布线，导致始终看不到 2.9.10+ 更新。
  - 改为通过 releases 列表检测最新版（`/releases/latest` 只返回非预发布的 2.7 线，而 wslc 以预发布形式发布）。
  - 升级改用 `wsl --update --pre-release`，不再走 winget（只跟稳定版）。

## 新增

- 网络页：查看、创建、删除、连接/断开容器、详情、清理未使用。
- 资源清理：容器、镜像、卷、网络一键 prune。
- 容器文件复制 `container cp`。
- 容器创建参数从 8 个扩展到 27 个（cpus、memory、hostname、workdir、user、entrypoint、network、stop-timeout、shm-size、tmpfs、gpus、健康检查、dns、ulimits、拉取策略等）。
- `inspect --size`、`list --size`、`image ls --all`、日志 `tail`/`timestamps`/`details`/`since`/`until`。

## 改进

- 会话配置真正生效：新增 `WslcSettingsFileService` 读写官方 settings.yaml 全部 8 个字段，保留注释与格式；`WslcRunner` 注入 `--session` 全局参数。
- 使用前校验会话是否存在：命名会话不存在时 wslc 会以 `WSLC_E_SESSION_NOT_FOUND` 失败，改为回退默认会话。
- `Microsoft.WSL.Containers` 2.9.9 升级到 2.9.12；该包只随 GitHub Release 发布，新增本地 nuget 源与拉取脚本，接入构建/发布/CI。

## 安装

- 安装包：WSLCC-Setup.exe
- 便携版：WSLCC-win-x64.zip
