# v1.4.1

修复 PATH 中缺少 WSL 时 `wslc.exe` 的解析问题。

## 修复

- `WslcRunner` 原先按裸名启动 `wslc.exe`，PATH 不含 WSL 安装目录的用户会收到原始 Win32Exception（系统找不到指定的文件，错误 2），且无任何修复提示。WSL 安装到 `C:\Program Files\WSL`，但不一定进入 PATH（全新安装、终端未重启、Store/MSIX 布局）。
  - 每进程解析一次可执行文件：先手动搜索 PATH，再回退已知安装位置（`Program Files\WSL\wslc.exe`、WindowsApps 别名），最后保留裸名兜底。
  - 将 Win32Exception（原生错误 2）映射为可读的 `WslcCliException`，说明搜索过的路径与修复方式。仪表盘指引识别新文案；设置页提示不再引用 winget（升级通道为 `wsl --update --pre-release`）。

## 安装

- 安装包：WSLCC-Setup.exe
- 便携版：WSLCC-win-x64.zip
