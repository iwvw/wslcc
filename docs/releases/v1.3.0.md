# v1.3.0

新增迷你容器面板。

## 新增

- 迷你面板：托盘唤出的右下角浮层（380x540 DIP），快速查看容器状态并启停/重启。
  - 独立窗口而非主窗口的一种模式，因生命周期与需求不同（轻量、高频、置顶）。
  - 仅由托盘图标开关，不做失焦自动隐藏（会与托盘点击竞争：点任务栏时窗口先失焦）。
  - 窗口置于最顶层带，但层级插在系统任务栏之下，从任务栏后方滑出且不被遮挡。
  - 单条常驻工作线程上做逐帧 `SetWindowPos` 滑动动画，以代数取消；`SWP_NOZORDER` 保持层级稳定不闪烁；显示时不淡入。
  - 自定义 SystemBackdrop 固定 `IsInputActive=true`，浮层非前台时亚克力不退化；关闭 Mica 时回退纯色。
  - 容器列表逐行启停/重启、映射端口时的打开按钮，每 3 秒轮询统计。
  - 托盘左键默认切换面板；新增 `app.trayMiniPanel` 设置恢复原行为（打开主窗口），并加入托盘右键菜单。主题与材质变化传导到浮层。

## 修复

- 容器端口解析支持 IPv4/IPv6 绑定（`0.0.0.0` 与 `[::]` 回退 localhost），打开按钮生成可用 URL。
- 发布脚本 `publish.ps1` 补上 `-p:PublishTrimmed=false`，与 CI 一致。Release 配置默认 `PublishTrimmed=true` 会裁剪 WinRT 类型，导致启动崩溃（XAML 绑定时 `WinRT.TypeExtensions` 空引用）；CI 一直覆盖而本地脚本没有。

## 改进

- 状态点改用 `Ellipse`（矢量抗锯齿）替代 `InfoBadge`，与容器名垂直居中。
- 迷你面板绑定改为 `Mode=OneWay`，刷新时状态文案即时更新；刷新按钮改为无边框图标 + 旋转指示 + 重入保护。
- 设置页：把关闭行为从会话分组移出（属于应用状态而非 wslc settings.yaml 选项），放进启动与托盘分组；wslc 管理的检查按钮改名为检查 WSL 更新，与关于页的应用更新检查区分。
