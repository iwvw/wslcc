# v1.1.0

会话健壮性、TUN 代理检测、Compose 目录迁移与本地化基础设施。

## 新增

- 代理 TUN 检测：识别代理 TUN 模式导致的 `E_UNEXPECTED`，并在界面给出提示。
- 本地化基础设施：动态文案走生成的 `AppStrings` 与 `L` 助手，跟随系统语言。

## 改进

- 容器操作原地更新，不再整页刷新；重启后保留端口信息。
- Compose 项目迁移到 `data/compose` 并自动迁移旧目录。
- 构建/发布/CI 裁剪多余的语言资源目录。

## 修复

- 会话终止/重启：等待 wslc 会话就绪后再刷新。
- 修复空页面骨架屏 `SkeletonGrid` 初始可见性问题。

## 安装

- 安装包：WSLCC-Setup.exe
- 便携版：WSLCC-win-x64.zip
