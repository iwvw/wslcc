# v1.0.0

首个正式发布版：基于官方 wslc CLI 的 WSL 容器桌面管理器，覆盖镜像、容器、Compose、卷、日志的图形化管理。

## 新增

- 容器管理：列表、启停、重启、删除、日志查看、详情、终端。
- 镜像管理：查看、删除、拉取记录、详情。
- Compose 编排：项目部署、编辑、重建、停止、删除。
- 卷与网络管理。
- 系统托盘图标（带主题适配菜单），关闭行为可配置。
- 自更新流程：检查、自动检查、安装器升级；wslc 安装与升级。
- 安装器与自包含便携包两种分发形式。

## 改进

- `WslcRunner` 改用 `ArgumentList` 传参，避免命令注入；收窄错误判定；取消时终止子进程。
- Compose：镜像标签处理、`depends_on` 键匹配、项目名清洗、部署记录 upsert。
- 数据库：`busy_timeout`、快照保留策略、写事务；移除无用的 `WslcApiHost` 与 `SessionStateRepository`。
- CI：从 tag 注入版本号，产出 zip 与安装器。

## 安装

- 安装包：WSLCC-Setup.exe
- 便携版：WSLCC-win-x64.zip
