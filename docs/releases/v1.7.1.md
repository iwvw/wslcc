# v1.7.1

托盘右键菜单改用 H.NotifyIcon.WinUI，获得 winUI Fluent 观感。

## 变更

- 弃用 WinForms `NotifyIcon` + `ContextMenuStrip`（纯 Win32 观感 + 自绘深色表），改为 `H.NotifyIcon.WinUI` 的 `TaskbarIcon` + 原生 `MenuFlyout`，在 `SecondWindow` 模式渲染，获得圆角、材质、主题跟随。
- 依赖升级到 `H.NotifyIcon.WinUI 2.5.0-beta.3`（修复首次打开宽度截断的预热测量；新增 `ContextMenuThemeMode` 跟随主题）。
- 新增 `TrayMenu.xaml`（`TaskbarIcon` + `ContextFlyout`，在 `App.xaml` 合并）与 `TrayIconService`（`Show`/`ApplyTheme`/`ShowBalloon`/`Dispose`、`ContextMenuThemeMode=System`、`ForceCreate(false)`、本地化菜单项）。
- 左键点击呼出迷你面板，菜单「打开 WSLCC」打开主窗口，新增「设置」入口；主题经 `App.ApplyTheme` 传导到托盘。

## 安装

- 安装包：WSLCC-Setup.exe
- 便携版：WSLCC-win-x64.zip
