# v1.6.0

同步官方 WSL 3.0.1（wslc GA），容器图标、迷你面板重做、部署进度可视化。

## 新增

- 容器 favicon 图标：探测每个可打开容器的 URL 抓取 favicon（link rel、常见路径、data: URI），缓存到 `%LOCALAPPDATA%\WSLCC\icons`；在打开按钮左侧显示，状态点不受影响。
- Compose 部署进度面板 `OperationProgressPanel`：分步计数 [i/N]、阶段行、可滚动日志与结果汇总。
- 容器创建参数：`--mount`、`--env-file`、`--domainname`、`--network-alias`、`-P`、`--no-healthcheck`。
- 仪表盘：从活动会话列表一键打开会话终端。
- 错误反馈：每个错误 InfoBar 支持一键复制诊断信息（环境 + 审计 + 应用日志）并跳转预填的 GitHub issue。
- 设置：托盘开关与下拉改为改动即保存；新增启动时最小化到托盘。

## 改进

- 同步 wslc GA：`Microsoft.WSL.Containers` 2.9.13 升级到 3.0.1；升级通道从 `wsl --update --pre-release` 改为 `wsl --update`（稳定版）；README、设置、事件页与 `WslcRunner` 中所有预发布/预览措辞改为 GA。
- 迷你面板：滑动缓动曲线、拖拽收起带回弹、多显示器任务栏处理；图标按钮带进度环；刷新与会话启停切换；底部显示描述性汇总、控件置顶、去掉 Ready 文案；与容器页共享 `ContainerIconService`，避免各自持有 HttpClient 与缓存。
- Compose：compose 文件持久化到配置目录而非 exe 同级 data 目录；相对卷挂载以持久化的 compose 文件目录为基准解析；本地已有同名镜像时复用，新增强制拉取最新选项（`--pull always` + 镜像加速）。
- 归一化 SVG `<style>` 类规则为内联样式，使 `SvgImageSource` 能正确渲染 OpenList 一类图标而非黑色方块。
- 主窗口：去掉返回按钮，侧栏收起按钮移入侧边栏，放大后的徽标与应用标题对齐。
- 内存优化：隐藏到托盘时释放主窗口页面内容并回收工作集（工作集约 180MB 降至约 40MB）。
