# v1.3.1

修复悬空的本地化键。

## 修复

- 三处 `L.Get` 引用了 `AppStrings` 中不存在的键，界面直接渲染了原始键名（`L.Get` 找不到时回退为键名本身）。问题在 v1.1.0 的本地化重构时引入，v1.2.0 与 v1.3.0 均存在。
  - `ComposePage.DeployAction`：缺失，编辑器主按钮显示 `ComposePage.DeployAction`。补「部署」/「Deploy」。
  - `ComposePage.CancelButton`：缺失，重建/停止/删除对话框的关闭按钮使用。补「取消」/「Cancel」。
  - `ContainersPage.DeleteButton`：键名写错，应指向已有的 `ContainersPage.DeleteButton.Content`。

## 安装

- 安装包：WSLCC-Setup.exe
- 便携版：WSLCC-win-x64.zip
