# v1.7.0

设置页重做、主题与背景材质切换、会话控制。

## 新增

- 设置页改用官方 Windows Community Toolkit `SettingsControls`（`SettingsExpander` 分组 + `SettingsCard` 行），Windows 11 设置式分组卡片。
- 外观：主题色下拉（浅色 / 深色 / 跟随系统）与背景材质下拉（亚克力 / Mica / 纯色），即时生效并同步迷你面板。
- 会话控制：迷你面板与仪表盘均可启停 wslc 会话。
- 启动时最小化到托盘；托盘开关与下拉改动即保存。

## 改进

- Compose：文件落到配置目录，相对卷以 compose 文件目录为基准；本地镜像优先复用，新增强制拉取最新；分步进度，支持后台继续与取消。
- 迷你面板：缓动动画、拖拽收起、多显示器任务栏、图标按钮、会话启停重排。
- 错误反馈：复制诊断并跳转预填的 GitHub issue。
- 隐藏到托盘后释放主窗口页面并回收工作集。

## 修复

- 主题切换失败：运行期写 `Application.Current.RequestedTheme` 会抛出空消息异常（启动后该属性不可修改），改为只切换根元素的 `RequestedTheme`。
- 停止会话后不再触发容器查询，避免会话被隐式拉起。

## 破坏性变更

- 移除强调色设置：外观不再提供自定义强调色，改为仅跟随系统。

## 安装

- 安装包：WSLCC-Setup.exe
- 便携版：WSLCC-win-x64.zip
