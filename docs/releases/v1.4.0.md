# v1.4.0

同步官方 wslc 2.9.13 能力。

## 新增

- `WslcCapabilities`：解析 `wslc --version`，按最低版本对新增参数做门控。这些参数在 2.9.12 上会被当作未知选项拒绝，旧版本必须回退而非注入。
- `image list --digests`：DIGEST 列 / json digest（门控）。
- `pull --all-tags`：拉取仓库全部标签（门控）。
- `container cp --follow-link`：复制时解析符号链接（门控）。
- `events`：容器与网络生命周期事件，支持 `--since`/`--until` 与可重复的 `--filter`；新增事件页，含有限历史查询与实时监听、过滤。
- 展示镜像 CreatedSince；安装的 wslc 低于 2.9.13 时隐藏不支持的控件。

## 改进

- `Microsoft.WSL.Containers` 2.9.12 升级到 2.9.13（拉取脚本默认版本同步更新）。

## 修复

- `wslc events` 不带 `--until` 会一直流式输出、永不退出，导致历史查询挂起；查询时注入 `--until`（当前秒 + 1；until 等于事件秒会丢掉该事件）。
- 2.9.13 启用 RedirectionGuard，拒绝穿越重解析点：`%LOCALAPPDATA%\wslc` 若为 junction 会让所有 wslc 操作以 0x800701c0 失败。已作为环境绕行方案记录（把 storagePath 指向真实目录）。
