# WSLC 容器管理器 — 产品概述

## 1. 产品定位

WSLC 容器管理器（WSLCC）是一款面向 Windows 开发者的桌面应用，提供对微软 WSL Containers（wslc）功能的图形化管理界面。用户在图形界面中完成容器与镜像的浏览、创建、运行、停止、删除和拉取等日常操作，无需记忆 wslc 命令行语法。

产品价值主张：

- 原生免费：基于 WSL 内置的 wslc 能力，无 Docker Desktop 授权成本、无守护进程、无 Docker Engine 依赖。
- 图形化：将命令行操作收敛为直观的列表、表单、进度与状态展示。
- 可控可审计：所有操作落库留痕，支持查看历史与诊断。
- 生产可维护：应用自身遵循分层架构，前后端解耦，数据持久化，异常可观测。

## 2. 目标用户

| 用户角色 | 特征 | 核心诉求 |
|---|---|---|
| 个人开发者 | 使用 WSL 做日常开发 | 快速拉取镜像、启停容器、查看状态 |
| 企业开发者 | 受 Intune/GPO 策略管控的环境 | 操作可控、行为可审计、网络受限下的降级可用 |
| 运维/DevOps | 需要批量管理容器 | 列表刷新、一键启停、错误信息明确 |

## 3. 产品范围

### 3.1 范围内（MVP 至 v1.0）

- 环境体检：wslc 版本、内核版本、Windows 版本、缺失组件、活动会话。
- 镜像管理：列表、拉取（实时进度）、删除、刷新。
- 容器管理：列表（名称/镜像/状态/端口）、新建（名称/镜像/端口映射/环境变量/自动删除/后台运行）、启动、停止、重启、删除。
- 会话管理：会话名称、存储路径、CPU 配额、内存配额的配置与持久化。
- 数据持久化：应用设置、操作审计日志、镜像拉取历史、容器状态快照，存储于本地 SQLite。
- 错误处理：统一错误展示（InfoBar），CLI/API 异常信息可读化。

### 3.2 范围外（v1.x 后续）

- 内置终端（连接容器 stdin/stdout 流）。
- Docker Compose 编排。
- 远程主机管理。
- 多会话并行管理。
- 镜像构建向导（Dockerfile）。

## 4. 约束与前提

- 目标平台：Windows 10 1809+（最低目标平台 10.0.17763），开发与运行目标 Windows 11。
- 依赖运行时：WSL 2.9.3+（含 wslc.exe 的预发布版），应用负责检测并在缺失时提示升级命令。
- 网络：拉取镜像依赖可访问的容器镜像仓库；网络受限时拉取功能会失败，应用须给出可读错误而非崩溃。
- 技术栈：WinUI 3（Windows App SDK 2.4.0）、.NET 10、CommunityToolkit.Mvvm、Microsoft.WSL.Containers（原生 API）、wslc CLI（兜底通道）、SQLite（Microsoft.Data.Sqlite）。

## 5. 成功标准

- 应用可在未安装 Windows App Runtime 的机器上自包含运行。
- 环境检测、镜像列表、容器列表三个核心读取能力在真实 wslc 环境下可用。
- 所有写操作（拉取/启停/删除/新建）在 wslc 可用时成功，不可用时给出明确错误原因。
- 应用设置、审计日志、拉取历史、容器快照持久化到 SQLite，重启后仍可读。
- 构建通过且无编译器警告（MVVMTK0045 等需清零）。
