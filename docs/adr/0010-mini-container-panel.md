# ADR-0010：迷你容器面板（右下角托盘浮层）

- 状态：Accepted

## 背景

容器启停是高频操作，但主窗口体积大、层级低，查看状态和启停需要先切回窗口，路径较长。需要一个常驻的轻量浮层，在托盘附近直接完成「看一眼容器状态 + 启停/重启」。

## 决策

新增独立窗口 `MiniWindow`（380×540 DIP，工作区右下角，距边 12 DIP），由托盘图标驱动显隐。

- **独立窗口而非主窗口变形**：职责与生命周期不同（浮层高频轻量、主窗低频完整），独立窗口状态机简单，动画逻辑只作用于浮层，且可常驻预热。
- **开关只由托盘驱动**：不做失焦自动收起。失焦隐藏与托盘点击切换存在竞态（点击任务栏图标会先触发窗口失活），去掉自动隐藏可从根上消除，行为也更可预测。
- **窗口层级**：置于 topmost 组，但插入任务栏正下方（`SetWindowPos(hwnd, Shell_TrayWnd, ...)`），实现从任务栏后方滑出、且不被其它窗口遮盖。顺序要求：`PlaceBelowTaskbar` 必须在 `BringToForeground` 之后。
- **滑入滑出动画**：`Window` 无内置显隐动画，采用逐帧 `SetWindowPos` 位移。单常驻工作线程 + 代际（generation）快照，新请求作废在途动画而非新建线程；每帧 `SWP_NOZORDER` 保证 z 序稳定不闪烁；展开不淡入（淡入会掩盖位移，看起来像凭空出现）。
- **材质**：自建 `SystemBackdrop` 把 `IsInputActive` 永久置 true 驱动 `DesktopAcrylicController`。内置 `DesktopAcrylicBackdrop` 在窗口非前台时退化为纯色，浮层不可用。关闭 Mica 设置时回退纯色背景。
- **内容**：复用 `IWslcContainerService` 拉取容器列表与 `stats`，3 秒轮询资源占用；每行提供启动/停止/重启，有端口映射时提供「打开」。面板常驻，不参与主窗口导航。
- **入口与开关**：托盘左键默认切换迷你面板，可在设置中关闭以恢复为直接打开主窗口；托盘右键菜单亦提供显隐项。持久化键 `app.trayMiniPanel`（默认开启）。

## 后果

- 正面：容器状态查看与启停路径缩短到一次托盘点击；动画、层级、材质按浮层需求独立演进，不影响主窗口。
- 负面：多一个常驻窗口的资源开销；依赖 `Shell_TrayWnd` 窗口类名做层级插入（Windows 长期稳定，但属实现细节），找不到任务栏时降级为纯 topmost；副屏任务栏类名不同（`Shell_SecondaryTrayWnd`），当前仅按主显示器工作区定位。
